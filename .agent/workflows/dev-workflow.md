# Workflow de Développement (dev-workflow.md)

1. **Vérification du PRD** : Contrôler que la tâche courante est bien couverte par le PRD validé.
2. **Planification Atomique** : Inscrire les sous-tâches dans `tasks/todo.md`.
3. **Implémentation Modulaire** : Réaliser les changements de manière progressive en isolant les fonctions.
4. **Vérification** : Lancer `npm run check` et tester le rendu WebGL.
5. **Revue & Documentation** : Mettre à jour `tasks/todo.md` et `tasks/lessons.md`.
